# UUIDNA QPU — an exact, formally verified quantum processing unit served over MCP

*Tsvetan Rouschev* · v1.4.0 · doi:[10.5281/zenodo.23156998](https://doi.org/10.5281/zenodo.23156998) · CC-BY-NC-ND-4.0 · https://qpu.uuidna.com

## Abstract

The Google Quantum AI layer as a TypeScript library with one MCP surface: the Willow processor as its spec sheet states
it, the Sycamore and Sycamore23 grids from Cirq's `known_devices`, a Cirq-style gate, circuit and simulator layer
(state vector and density matrix), the Quantum Echoes protocol with the benchmark Google states, the textbook
algorithms of the Cirq page (QFT, phase estimation, Grover, teleportation, QAOA, Shor for N ≤ 21), numpy's Mersenne
Twister so the QAOA page's instance is reproduced exactly, and a registry of every lead followed on quantumai.google.
Beside it, a Lean 4 library `Qpu` of theorems about the unit's integers (the table below counts them), checked by the Lean kernel with no `sorry`
and no axiom beyond `propext` and `Quot.sound`. The MCP handler is a pure function: it imports nothing from Node,
performs no I/O, and returns each result with a widget. There is no server, no network access and no hardware access
in this tree.

## 3. Bounds

Shor runs as a phase-estimation circuit on the state-vector simulator and is bounded to N ≤ 21; `shorFactors` recovers
the order by continued fractions (N = 15, a = 7 gives order 4 and factors 3 × 5, asserted in the tests). The other
algorithms are bounded by the simulator's state-vector size, and each bound is declared in the tool's input schema.
No order or factor beyond those bounds is computed anywhere in this tree.

## 4. What the Lean library proves, and what it does not

The theorems are statements about natural numbers computed by the unit's own definitions: `Mint` (doubling and
binomials, with `mintOf (a + b) = mintOf a * mintOf b` by induction), `Lattice` and `Cross` (identities between the
unit's named constants), `Clay` (55 `relation_N` theorems, each stating that two or three of the unit's expressions
evaluate to the same integer N, closed by `rfl`), `Shor` (`powMod`, `periodOf`, `gcdOf` as fuelled recursions, and
the theorem that for the fixed base and modulus the period is even and the two gcds are proper factors), `Sigma`
(`σ_d(x) = d − x` is an involution on `[0, d]`, fixed at the midpoint, by `omega`), `Primes`, `Combinatorics`, `Pi`,
`Physics` (ratios between stated constants). They are checked by the kernel; the census above was taken with
`collectAxioms` over every theorem in the `Qpu` modules.

They do not state or prove any Clay Millennium problem, any asymptotic speedup, or any property of Google's hardware.
`Clay.lean` is named for the unit's "clay" register of constants; its theorems are integer identities.

The five files under `leads/` (CausalInference, ExplainableAI, FederatedLearning, ProgramSynthesis, ZeroShotLearning,
HarmonicClosure) are not imported by the library and do not compile: they use `Finset` and `ℝ` from Mathlib, which this
package does not depend on, and together they declare 187 theorems with 61 `sorry` placeholders over 226 axioms. They
are kept as sketches and count for nothing above.

## 5. Figures that are Google's, not this tree's

The processor figures (105 qubits; error medians per chip; a 40-fold error reduction and 99.99% logical T-state
fidelity from magic-state cultivation), the Sycamore figures (54 qubits, 88 couplers), the Quantum Echoes benchmark
(13,000×; about 2 hours on Willow against 3.2 years per data point on Frontier) and the roadmap milestones are served
as Google states them and are labelled so in the source. The tests check the grid-derived values (coupler count,
average connectivity) against the stated ones; they do not and cannot verify Google's measurements.

npm test

import { handle } from './src/quantum/mcp.ts'
const reply = await handle({ jsonrpc: '2.0', id: 1, method: 'tools/call',
  params: { name: 'algorithm', arguments: { name: 'shor', N: 15, a: 7 } } })

## 8. Scope, and what this tree is not

- It is a library and an in-process MCP handler. It does not listen on a port. The hosted endpoint at
  https://qpu.uuidna.com is deployed separately and is not built from this tree.
- Its formal-verification claim is exactly §4: 216 kernel-checked integer theorems about the unit's own definitions,
  nothing about open problems or hardware.
- It does not factor anything beyond N ≤ 21 and claims no quantum advantage of its own.
- The full v1.4.0 tree (the lattice, the receipts, the Payload site) is the history this branch grows from; see the
  repository's `main`.
