# @uuidna/qpu

QPU (quantum processing unit) worker at [https://qpu.uuidna.com](https://qpu.uuidna.com). Three readings, one machine.

```ts
import { handleQpuFetch, qpuMachineOf } from '@uuidna/qpu'
```

| Path | Reading |
| --- | --- |
| `/` | discovery + machine |
| `/seat` | `QPU` · `empty` |
| `/width` | CPU GPU RAM CACHE STORAGE |
| `/hologram` | foundation 0, debit 3, credit 6, pentagram 5, fold 7, octet 8, VE 14 |
| `/.well-known/qpu.json` | discovery |

```
npm install @uuidna/qpu
npx wrangler deploy
```

A GitHub release is archived on Zenodo from [`.zenodo.json`](.zenodo.json). Cite with [`CITATION.cff`](CITATION.cff).
