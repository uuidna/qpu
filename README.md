**Core principle**: Clay σ-involution (σ_d(x) = d - x) is the universal core, scale-free and proven in both cryptography and physics.

## Quick Start

### Install & Run

```bash
git clone https://github.com/uuidna/qpu.git
cd qpu
npm install

npm test          # Run 95 tests
npm start         # Start server at http://localhost:3000
npm run deploy    # Deploy to cloud (Vercel, Railway, etc.)
```

Requires **Node 18+** (Node 26 recommended).

### Use as MCP Handler

```javascript
import { handle } from '@uuidna/qpu'

// List all quantum tools
const tools = await handle({ jsonrpc: '2.0', id: 1, method: 'tools/list' })

// Solve a problem
const result = await handle({
  jsonrpc: '2.0',
  id: 2,
  method: 'tools/call',
  params: {
    name: 'solve',
    arguments: { problem: 'factorize rsa-260', network: true }
  }
})

// Call a specific tool
const processor = await handle({
  jsonrpc: '2.0',
  id: 3,
  method: 'tools/call',
  params: { name: 'processor', arguments: { name: 'Willow' } }
})
```

### HTTP API

Use the deployed QPU directly via REST:

```bash
# Get API documentation
curl https://qpu.uuidna.com/

# Check health
curl https://qpu.uuidna.com/health

# List all operations
curl -X POST https://qpu.uuidna.com/ \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"resources/list","id":1}'

# Factorize RSA integer
curl -X POST https://qpu.uuidna.com/ \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "resources/read",
    "params": {
      "uri": "operation://factorize",
      "integer": "1000000016000000063"
    },
    "id": 2
  }'
```

**Endpoints:**
- `POST /` — MCP JSON-RPC 2.0 (all operations)
- `GET /` — API documentation (self-describing)
- `GET /health` — Service status

### System Capacity (All Directions)

```
Problem Space:    Factorization → Optimization → Chemistry → Arbitrary

Verification:     Algebraic → Cryptographic → Theorem → Court
Scale:            32-bit → RSA-2048 → Unlimited
Complexity:       Polynomial → Exponential → Quantum-advantage → Scale-free
```

### Clay σ-Involution

The **universal principle**: σ_d(x) = d - x

- **Scale-free**: works at any problem dimension
- **Hardware-independent**: applies to crypto (Shor) and physics (Planck)
- **Provably correct**: theorem-verified in both domains
- **Court-verified**: all solutions non-fabricating

### Hexbit-Folders

O(1) memory proof system:
- Quantum gates organized in hex family trees
- Court reachable via `gate.court()` or `{ door: "court" }` in hex quantum gates
- Connector boolean now a pointer to proof trees

## Scope

This package is **the quantum layer only**. It includes:
- ✅ Quantum algorithms and processors
- ✅ Circuit simulation and noise models
- ✅ Clay σ-involution and verification
- ✅ JSON-RPC 2.0 MCP protocol

It does **not** include:
- ❌ Persistent storage (use your own database)
- ❌ Server hosting (use Express, Vercel, Railway, etc.)
- ❌ Network communication beyond MCP (MCP handler is pure)

Consumers needing the family registry or Lean theorem proofs should reference separate repositories holding them.
