# UUIDNA QPU

**Quantum Processing Unit - Autonomous MCP-Driven System**

> For complete documentation, see [`docs/README.md`](./docs/README.md)

## Quick Start

```bash
# Install
npm install

# Build
npm run build

# Test
npm test

# View system status
npm run status

# Run gap-filling
npm run gaps:fill

# Deploy
npm run ship
```
