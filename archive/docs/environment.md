# Environment

Sandboxed fused environment. QPU auto-recognizes Worker bindings, `process.env`, host ISA, CPU cores, and WebGPU, then fuses them into one reading.

Fuse is HTTP GET of named domains only — no wildcards. Experiments unlimited. When never. The chip named QPU stays empty.

::: info JSON
`curl -sS https://qpu.uuidna.com/environment`
:::
