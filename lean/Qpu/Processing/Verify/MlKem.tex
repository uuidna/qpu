\paragraph{\texttt{Qpu.Verify.MlKem.ind\_cpa\_of\_mlwe}}
IND-CPA of K-PKE from Module-LWE hardness as an explicit hypothesis: when no distinguisher has advantage above `δ₁` on the key problem nor above `δ₂` on the encryption problem, no adversary has IND-CPA advantage above `δ₁ + δ₂`. Composed from `Qpu.Verify.MlKem.ind\_cpa\_reduces\_to\_mlwe` with Mathlib's `le\_trans` and `add\_le\_add`, the order of the reals `Real.instIsOrderedAddMonoid`, `IsOrderedAddMonoid.toAddLeftMono` and `covariant\_swap\_add\_of\_covariant\_add`, and the numeral `Nat.instAtLeastTwoHAddOfNat`.
\[ \forall \{M\ S\ V\ U\ W\ \mathrm{Msg} \sigma : \mathrm{Type}\} [\mathrm{inst} : \mathrm{AddCommGroup}\ V] [\mathrm{inst\_1} : \mathrm{Fintype}\ V] [\mathrm{inst\_2} : \mathrm{Nonempty}\ V] [\mathrm{inst\_3} : \mathrm{AddCommGroup}\ U] [\mathrm{inst\_4} : \mathrm{Fintype}\ U] [\mathrm{inst\_5} : \mathrm{Nonempty}\ U] [\mathrm{inst\_6} : \mathrm{AddCommGroup}\ W] [\mathrm{inst\_7} : \mathrm{Fintype}\ W] [\mathrm{inst\_8} : \mathrm{Nonempty}\ W] (\mathrm{mul} : M \to S \to V) (\mathrm{mat} : \mathrm{PMF}\ M) (\mathrm{secret} : \mathrm{PMF}\ S) (\mathrm{noise} : \mathrm{PMF}\ V) (\mathrm{dotT} : M \to V \to S \to U \times W) (\mathrm{coins} : \mathrm{PMF}\ S) (\mathrm{noise}_{12} : \mathrm{PMF} (U \times W)) (\mathrm{encode} : \mathrm{Msg} \to W) (\mathrm{choose} : M \times V \to \mathrm{PMF} (\mathrm{Msg} \times \mathrm{Msg} \times \sigma )) (\mathrm{guess} : \sigma \to U \times W \to \mathrm{PMF}\ \mathrm{Bool}) (\delta _{1} \delta _{2} : \mathbb{R}), \mathrm{have}\ \mathrm{keyReal} := \mathrm{mat.bind}\ \lambda \ A \mapsto \mathrm{secret.bind}\ \lambda \ s \mapsto \mathrm{noise.bind}\ \lambda \ e \mapsto \mathrm{PMF.pure} (A, \mathrm{mul}\ A\ s + e); \paragraph{\texttt{Qpu.Verify.MlKem.ind\_cpa\_reduces\_to\_mlwe}}
The reduction from IND-CPA of K-PKE to Module-LWE: for every adversary `(choose, guess)`, the advantage of the IND-CPA game `keyReal.bind cpa` over a coin flip is at most the advantage of the distinguisher `cpa` on the key problem (`keyReal` against `keyRand`) plus the advantage of the distinguisher `encD` on the encryption problem (`encReal` against `encRand`). The first hop: with a random key the IND-CPA game is `encReal.bind encD`. The second: with random samples the uniform `c` shifted by the message is uniform, so `encD` outputs a uniform bit. Proved with Mathlib's `PMF.bind\_bind`, `PMF.pure\_bind`, `PMF.bind\_map`, `PMF.bind\_comm`, `PMF.bind\_const`, `PMF.uniformOfFintype\_apply`, `sub\_add\_cancel`, `add\_sub\_cancel\_right`, `Prod.mk.eta`, `ENNReal.toReal\_inv`, `ENNReal.toReal\_ofNat`, `one\_div` and `abs\_sub\_le` in the reals ordered by `Real.instIsOrderedAddMonoid`, the numeral `Nat.instAtLeastTwoHAddOfNat`, and `Qpu.Verify.MlKem.uniform\_shift` and `Qpu.Verify.MlKem.uniform\_eq\_bit` from this module.

\mathrm{have}\ \mathrm{keyRand} := \mathrm{mat.bind}\ \lambda \ A \mapsto (\mathrm{PMF.uniformOfFintype}\ V)\mathrm{.bind}\ \lambda \ t \mapsto \mathrm{PMF.pure} (A, t); \mathrm{have}\ \mathrm{cpa} := \lambda \ \mathrm{pk} \mapsto \mathrm{coins.bind}\ \lambda \ r \mapsto \mathrm{noise}_{12}\mathrm{.bind}\ \lambda \ e \mapsto (\mathrm{PMF.uniformOfFintype}\ \mathrm{Bool})\mathrm{.bind}\ \lambda \ b \mapsto (\mathrm{choose}\ \mathrm{pk})\mathrm{.bind}\ \lambda \ x \mapsto (\mathrm{guess}\ \mathrm{x.2.2} ((\mathrm{dotT}\ \mathrm{pk.1}\ \mathrm{pk.2}\ r + e)\mathrm{.1}, (\mathrm{dotT}\ \mathrm{pk.1}\ \mathrm{pk.2}\ r + e)\mathrm{.2} + \mathrm{encode} (\mathrm{if}\ b = \mathrm{true}\ \mathrm{then}\ \mathrm{x.2.1}\ \mathrm{else}\ \mathrm{x.1})))\mathrm{.bind}\ \lambda \ b' \mapsto \mathrm{PMF.pure} (b' = b); \mathrm{have}\ \mathrm{encReal} := \mathrm{keyRand.bind}\ \lambda \ \mathrm{pk} \mapsto \mathrm{coins.bind}\ \lambda \ r \mapsto \mathrm{noise}_{12}\mathrm{.bind}\ \lambda \ e \mapsto \mathrm{PMF.pure} (\mathrm{pk}, \mathrm{dotT}\ \mathrm{pk.1}\ \mathrm{pk.2}\ r + e); \mathrm{have}\ \mathrm{encRand} := \mathrm{keyRand.bind}\ \lambda \ \mathrm{pk} \mapsto (\mathrm{PMF.uniformOfFintype} (U \times W))\mathrm{.bind}\ \lambda \ c \mapsto \mathrm{PMF.pure} (\mathrm{pk}, c); \mathrm{have}\ \mathrm{encD} := \lambda \ y \mapsto (\mathrm{PMF.uniformOfFintype}\ \mathrm{Bool})\mathrm{.bind}\ \lambda \ b \mapsto (\mathrm{choose}\ \mathrm{y.1})\mathrm{.bind}\ \lambda \ x \mapsto (\mathrm{guess}\ \mathrm{x.2.2} (\mathrm{y.2.1}, \mathrm{y.2.2} + \mathrm{encode} (\mathrm{if}\ b = \mathrm{true}\ \mathrm{then}\ \mathrm{x.2.1}\ \mathrm{else}\ \mathrm{x.1})))\mathrm{.bind}\ \lambda \ b' \mapsto \mathrm{PMF.pure} (b' = b); \paragraph{\texttt{Qpu.Verify.MlKem.ml\_kem\_768\_ind\_cpa\_reduces\_to\_mlwe}}
IND-CPA of ML-KEM-768's K-PKE (FIPS 203) reduced to Module-LWE with k = 3, n = 256, q = 3329: with the product of `ZMod 3329[X]/(X²⁵⁶ + 1)` (`mulRq`, `X²⁵⁶ = -1`), the uniform 3 × 3 matrix, the centred binomial secrets and noise with η₁ = η₂ = 2 and the message encoded as 1665, every adversary's IND-CPA advantage is at most the advantage of the distinguisher built from it on Module-LWE with the 3 × 3 matrix `A` plus that of the one built from it on Module-LWE with the 4 × 3 matrix `(A, t)`. The instance of `Qpu.Verify.MlKem.ind\_cpa\_reduces\_to\_mlwe`, with the numeral `Nat.instAtLeastTwoHAddOfNat`.

\paragraph{\texttt{Qpu.Verify.MlKem.uniform\_eq\_bit}}
Comparing any bit with a uniform bit gives a uniform bit. Proved with `Qpu.Verify.MlKem.uniform\_shift`.
\[ \forall (b' : \mathrm{Bool}), ((\mathrm{PMF.uniformOfFintype}\ \mathrm{Bool})\mathrm{.bind}\ \lambda \ b \mapsto \mathrm{PMF.pure} (b' = b)) = \mathrm{PMF.uniformOfFintype}\ \mathrm{Bool} \]

\paragraph{\texttt{Qpu.Verify.MlKem.uniform\_shift}}
A uniform distribution moved by a bijection is uniform. Proved with Mathlib's `PMF.ext`, `PMF.map\_apply`, `tsum\_eq\_single` with `SummationFilter.instLeAtTopUnconditional`, and `PMF.uniformOfFintype\_apply`.
