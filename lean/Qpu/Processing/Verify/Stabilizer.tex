\paragraph{\texttt{Qpu.Verify.Stabilizer.conjCnotSigned\_agrees\_with\_ruleCNOT}}
The signed CNOT rule agrees with the phase-aware matrix-level rule: same phase parity and same Pauli-bit updates.
\[ \forall (k : \mathbb{N}) (\mathrm{ct} : \mathrm{Qpu.Verify.Stabilizer.P1} \times \mathrm{Qpu.Verify.Stabilizer.P1}), \mathrm{CircuitBasedQuantumComputing.ruleCNOT} \{ k := k, \mathrm{x0} := \mathrm{ct.1.x}, \mathrm{z0} := \mathrm{ct.1.z}, \mathrm{x1} := \mathrm{ct.2.x}, \mathrm{z1} := \mathrm{ct.2.z} \} = \{ k := (k + \mathrm{if} (\mathrm{ct.1.x} \land \mathrm{ct.2.z} \land \mathrm{ct.2.x} = \mathrm{ct.1.z}) = \mathrm{true}\ \mathrm{then}\ 2\ \mathrm{else}\ 0) \bmod 4, \mathrm{x0} := \mathrm{ct.1.x}, \mathrm{z0} := \mathrm{ct.1.z} ^{}^{\mathrm{ct.2.z}}, \mathrm{x1} := \mathrm{ct.1.x} ^{}^{\mathrm{ct.2.x}}, \mathrm{z1} := \mathrm{ct.2.z} \} \]
\noindent axioms: none; proof: \url{https://github.com/uuidna/qpu/blob/v1.1.1/lean/Qpu/Processing/Verify/Stabilizer.lean\#L309}

\paragraph{\texttt{Qpu.Verify.Stabilizer.conjCnotSigned\_matches\_ruleCNOT}}
The signed CNOT rule is exactly the rule appearing in the proved `Exact CNOT` proposition, with its Boolean phase encoding the parity of the rule's `i\^{}k` phase.
\[ \forall (k : \mathbb{N}) (\mathrm{ct} : \mathrm{Qpu.Verify.Stabilizer.P1} \times \mathrm{Qpu.Verify.Stabilizer.P1}), \mathrm{CircuitBasedQuantumComputing.ruleCNOT} \{ k := k, \mathrm{x0} := \mathrm{ct.1.x}, \mathrm{z0} := \mathrm{ct.1.z}, \mathrm{x1} := \mathrm{ct.2.x}, \mathrm{z1} := \mathrm{ct.2.z} \} = \{ k := (k + \mathrm{if} (\mathrm{Qpu.Verify.Stabilizer.conjCnotSigned}\ \mathrm{ct})\mathrm{.1} = \mathrm{true}\ \mathrm{then}\ 2\ \mathrm{else}\ 0) \bmod 4, \mathrm{x0} := (\mathrm{Qpu.Verify.Stabilizer.conjCnotSigned}\ \mathrm{ct})\mathrm{.2.1.x}, \mathrm{z0} := (\mathrm{Qpu.Verify.Stabilizer.conjCnotSigned}\ \mathrm{ct})\mathrm{.2.1.z}, \mathrm{x1} := (\mathrm{Qpu.Verify.Stabilizer.conjCnotSigned}\ \mathrm{ct})\mathrm{.2.2.x}, \mathrm{z1} := (\mathrm{Qpu.Verify.Stabilizer.conjCnotSigned}\ \mathrm{ct})\mathrm{.2.2.z} \} \]
\noindent axioms: none; proof: \url{https://github.com/uuidna/qpu/blob/v1.1.1/lean/Qpu/Processing/Verify/Stabilizer.lean\#L321}

\paragraph{\texttt{Qpu.Verify.Stabilizer.stabilizer\_cz\_commutation\_rule}}
CZ fixes a two-qubit Pauli exactly when neither qubit has X support: an X on either qubit puts a Z on the other (CZ·(I⊗X)·CZ = Z⊗X).
\[ \forall (\mathrm{ct} : \mathrm{Qpu.Verify.Stabilizer.P1} \times \mathrm{Qpu.Verify.Stabilizer.P1}), \mathrm{Qpu.Verify.Stabilizer.conjCz}\ \mathrm{ct} = (\mathrm{false}, \mathrm{ct.1}, \mathrm{ct.2}) \leftrightarrow \mathrm{ct.1.x} = \mathrm{false} \land \mathrm{ct.2.x} = \mathrm{false} \]
\noindent axioms: none; proof: \url{https://github.com/uuidna/qpu/blob/v1.1.1/lean/Qpu/Processing/Verify/Stabilizer.lean\#L238}
