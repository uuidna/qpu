\paragraph{\texttt{cooling\_stays\_positive}}
COOLING: for every t, a, n with 0 < t and 0 < a, 0 < t * a \^{} n; with a < b as well, t * a \^{} n * a < t * a \^{} n * b.
\[ \forall (t\ a\ n : \mathbb{N}), 0 < t \to 0 < a \to 0 < t \cdot a ^{n} \]
\noindent axioms: none; proof: \url{https://github.com/uuidna/qpu/blob/v1.1.1/lean/Qpu/Physics/EnergyGap.lean\#L31}

\paragraph{\texttt{cooling\_strictly\_decreases}}
\[ \forall (t\ a\ b\ n : \mathbb{N}), 0 < t \to 0 < a \to a < b \to t \cdot a ^{n} \cdot a < t \cdot a ^{n} \cdot b \]
\noindent axioms: none; proof: \url{https://github.com/uuidna/qpu/blob/v1.1.1/lean/Qpu/Physics/EnergyGap.lean\#L33}

\paragraph{\texttt{gap\_doubles}}
One more level exactly doubles the gap, for every k.
\[ \forall (k : \mathbb{N}), \mathrm{levelGap} (k + 1) = 2 \cdot \mathrm{levelGap}\ k \]
\noindent axioms: \texttt{propext}, \texttt{Quot.sound}; proof: \url{https://github.com/uuidna/qpu/blob/v1.1.1/lean/Qpu/Physics/EnergyGap.lean\#L57}

\paragraph{\texttt{gap\_monotone}}
The gap never shrinks with level, for all level pairs.
\[ \forall \{k\ k' : \mathbb{N}\}, k \le k' \to \mathrm{levelGap}\ k \le \mathrm{levelGap}\ k' \]
\noindent axioms: none; proof: \url{https://github.com/uuidna/qpu/blob/v1.1.1/lean/Qpu/Physics/EnergyGap.lean\#L45}

\paragraph{\texttt{gap\_pos}}
Every level has a positive gap, for every k.
\[ \forall (k : \mathbb{N}), 0 < \mathrm{levelGap}\ k \]
\noindent axioms: none; proof: \url{https://github.com/uuidna/qpu/blob/v1.1.1/lean/Qpu/Physics/EnergyGap.lean\#L51}

\paragraph{\texttt{gap\_strict}}
The gap strictly grows with level, for every k.
\[ \forall (k : \mathbb{N}), \mathrm{levelGap}\ k < \mathrm{levelGap} (k + 1) \]
\noindent axioms: none; proof: \url{https://github.com/uuidna/qpu/blob/v1.1.1/lean/Qpu/Physics/EnergyGap.lean\#L54}

\paragraph{\texttt{physics\_all}}
The textbook spot values, decided by the kernel as controls on the general laws.
\[ \mathrm{levelGap}\ 0 = 1 \land \mathrm{levelGap}\ 1 = 2 \land \mathrm{levelGap}\ 2 = 4 \land \mathrm{levelGap}\ 3 = 8 \]
\noindent axioms: none; proof: \url{https://github.com/uuidna/qpu/blob/v1.1.1/lean/Qpu/Physics/EnergyGap.lean\#L62}
