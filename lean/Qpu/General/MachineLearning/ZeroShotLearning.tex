\paragraph{\texttt{Qpu.ZeroShot.semantic\_transitivity}}
Honest replacement of the sketch's "semantic transitivity": if `a` agrees with `b` and `b` with `c` on all but `k` attributes each, then `a` agrees with `c` on all but `2k`. (The sketch asserted `0.8, 0.8 → 0.6` for undefined real similarities.)
\[ \forall (a\ b\ c : \mathrm{Qpu.ZeroShot.Attr}) (k : \mathbb{N}), \mathrm{List.length}\ a = \mathrm{List.length}\ b \to \mathrm{List.length}\ b = \mathrm{List.length}\ c \to \mathrm{List.length}\ a \le \mathrm{Qpu.ZeroShot.agree}\ a\ b + k \to \mathrm{List.length}\ a \le \mathrm{Qpu.ZeroShot.agree}\ b\ c + k \to \mathrm{List.length}\ a \le \mathrm{Qpu.ZeroShot.agree}\ a\ c + 2 \cdot k \]
\noindent axioms: \texttt{propext}, \texttt{Classical.choice}, \texttt{Quot.sound}; proof: \url{https://github.com/uuidna/qpu/blob/v1.1.1/lean/Qpu/General/MachineLearning/ZeroShotLearning.lean\#L143}
