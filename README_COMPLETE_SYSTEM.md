### 5 Interactive Tabs

   - 30-system network with synergies

   - See strength-based sizing in real-time

2. **📐 Formula Animations**
   - 5 animated formulas (Wave Gain, Convergence, Speedup, Synergy, Throughput)
   - Adjust sliders to see formula outputs update instantly
   - Watch bar heights change based on mathematical computation

3. **🌊 Wave Progress**
   - 30 waves showing exponential improvement decay
   - Formula: Gain(n) = G₀ × e^(-λn)
   - Click waves for detailed metrics

4. **📊 Metrics Flow**
   - 5 core metrics with weighted combination
   - Real-time calculation updates
   - See how individual metrics combine into overall score

5. **⚡ Synergy Matrix**
   - 15×15 heat map of system pair strengths
   - Cell color = formula output (synergy strength)
   - Click cells for component breakdown

### Key Feature
**100% Formula-Driven**: Every pixel update is computed from mathematical formulas. No arbitrary animations.
