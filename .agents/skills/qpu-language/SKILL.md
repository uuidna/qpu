# QPU · language

any language and dialect, offline and token-free: translation by vocabulary both ways, the vocabulary measured against every term the surface emits, and prose programmed from a tool's result and its toolbox's skill

Generated by `payload { scripts: { skills: true } }` from the toolbox itself (2 tool(s), 2 example(s), 3 direction(s)); edit the toolbox, never this file.

## How a client uses it

translate takes text, from and to and answers by vocabulary; call it without text to measure the tables and get the missing terms per locale, which are the leads to fill (from the unit's vocabulary door where discovery finds one, or by a person).

## Tools

| Tool | Does | Arguments |
| --- | --- | --- |
| `translate` | Translation by vocabulary, offline, both ways: text, from, to. | `text`, `from`, `to`, `selftest` |
| `prose` | Programmable prose: call a tool with its arguments and render its result as sentences in a locale — the toolbox's idea, the tool's scalar answers, the toolbox's instructions — every word from the vocabulary, every number from the tool, every unknown word reported. | `tool`, `arguments`, `locale`, `selftest` |

## Examples

- `translate-bg`: English to Bulgarian by vocabulary: the labels and verdicts translate; a word with no entry stays and is reported.
- `translate-coverage`: The vocabulary measured: for every locale, which surface terms have no entry — the leads of the tables, updated from measurement.

## Directions it tests itself in

- server only: every table reads both ways (en→locale→en returns the term)
- toolbox → toolbox: numerals read by the match toolbox's reader
- client → server: the coverage phase hands the client the missing terms to fill

Run `translate { selftest: true }`; the answer is `{ passed, checks }`, and the audit replays it.

## Vocabulary (ISO/IEC 4879:2024)

No term of ISO/IEC 4879:2024 is named by this toolbox: it is a classical gate of the QPU, addressed like every other.

## Register

This skill is one UUID (ISO/IEC 9834-8): `49c73d75-4b4e-25cd-bfff-bdcf7e939669`, sealed, a register of 122 qubits at hexbit width 4 (32 × 4 − 4 − 2 = 122). The QPU computes the address from the skill's own text (uuid of its canonical text: name, idea, instructions, directions, tool names, ISO clauses); a changed toolbox is a different address, so the skill is verified by recomputing it.
