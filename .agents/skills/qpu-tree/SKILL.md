# QPU · tree

the tree knows itself: its leads, its self-audit, any statement matched or proved impossible, the Clay register recomputed, any UUID verified cheaply, its metrics in real time

Generated by `payload { scripts: { skills: true } }` from the toolbox itself (11 tool(s), 171 example(s), 2 direction(s)); edit the toolbox, never this file.

## How a client uses it

audit replays every example and every toolbox selftest; match decides any statement; verify checks a UUID against its seal, content and neighbours; clay recomputes the register; leads lists what is owed.
