# Citing QPU

If you use QPU in your research, education, or projects, please cite it. We provide citation formats for common systems.

## Quick Citation

**BibTeX:**
```bibtex
@software{qpu2026,
  author = {Anthropic},
  title = {QPU: Quantum Processing Unit MCP Server},
  year = {2026},
  url = {https://github.com/anthropics/claude-code-qpu},
  version = {2.0.0},
  license = {CC-BY-NC-ND-4.0}
}
```

**APA:**
```
Anthropic. (2026). QPU: Quantum Processing Unit MCP Server (Version 2.0.0) [Computer software]. 
https://github.com/anthropics/claude-code-qpu
```

**MLA:**
```
Anthropic. "QPU: Quantum Processing Unit MCP Server." GitHub, 2026, 
https://github.com/anthropics/claude-code-qpu. Version 2.0.0.
```

**Chicago:**
```
Anthropic. "QPU: Quantum Processing Unit MCP Server." Version 2.0.0. Accessed October 24, 2026. 
https://github.com/anthropics/claude-code-qpu.
```

## In Research Papers

When citing QPU in academic work, please reference:

1. **The QPU repository** (this software)
2. **Relevant foundational papers:**
   - Shor, P. W. (1994). Algorithms for quantum computation: discrete logarithms and factoring.
   - Google Quantum AI. (2024). Willow: A 3D-transmon quantum processor with surface codes.
   - Farhi, E., Goldstone, J., & Gutmann, S. (2014). A Quantum Approximate Optimization Algorithm.
   - Gidney, C., & Ekera, M. (2021). How to factor 2048 bit RSA integers in 8 hours using 20 million noisy qubits.

3. **Implementation frameworks:**
   - Cirq: A Python framework for quantum circuits
   - quantumlib: Google's quantum computing software packages

## Citation File Format (CFF)

The repository includes a `CITATION.cff` file in the standard [Citation File Format](https://citation-file-format.github.io/). This allows automatic citation generation in tools like GitHub and Zenodo.

Read the `CITATION.cff` file for complete metadata in machine-readable format.
