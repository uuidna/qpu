## The competition of codes

An uncorrectable combination lists its possibilities: every value some copies hold.

The rules, judged on every run: (1) a code decides from the copies that had arrived by its decision time; (2) the fastest code whose decision is the consensus wins; (3) a tie goes to the stronger code; (4) a code is correct only when its decision is the consensus; (5) no winner without a consensus.
