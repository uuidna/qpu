## Architecture Decisions

### Why Waves?
- **Parallel execution**: Solves multiple problems simultaneously
- **Scalability**: Easy to add more parallelism
- **Reliability**: One problem failure doesn't stop others
- **Monitoring**: Clear status for each wave
- **Streaming**: Results as they complete

### Why Layered?
- **Separation of concerns**: Each layer has single responsibility
- **Reusability**: Layers work independently
- **Maintainability**: Easy to update individual components
- **Testing**: Each layer testable separately

### Why MCPs?
- **Modularity**: Each MCP handles its domain
- **Extensibility**: Add new MCPs without changing core
- **Compatibility**: Uses standard MCP protocol
- **Ecosystem**: Leverages public MCP infrastructure
