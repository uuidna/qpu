# Chat: the MCP itself

A statement typed here is a `tools/call` to the handler running in this page — the MCP is the chat. The answer is a block at its content address; the same call is named to the host by the block's content hash, and a `304` is the teleport: the host holds the same block, nothing is sent, the analog is verified digitally here in full. Every exchange is signalled to every open tab of the web OS; the log stays on this device. Offline, the handler answers alone and says so.
