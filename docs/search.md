# Universal Search Interface

**Native VitePress Search - Problems, MCPs, Prizes, Financing**

---

## 🔍 How to Search

Click the **search icon** in the navigation bar (top right) or press <kbd>⌘</kbd><kbd>K</kbd> (Mac) / <kbd>Ctrl</kbd><kbd>K</kbd> (Windows/Linux) to open VitePress's native search.

The search indexes all pages and surfaces results in real-time as you type.

### Problem Search
- Search by name: "RSA-260", "MaxCut", "TSP"
- Search by algorithm: "Shor", "QAOA", "VQE"
- Search by status: "solved", "solving", "open"

### Financing Search
- Search by type: Grant, Revenue share, Bounty
