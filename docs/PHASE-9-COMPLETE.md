### Tier 3: 5 Orchestration Patterns

**Pattern 1: Sequential Pipeline**
```
Input → [Formula A] → [Formula B] → [Formula C] → Output
├─ Deterministic
├─ Ordered execution
└─ Use case: Data transformation
```

**Pattern 2: Parallel Fanning**
```
Input → ┬→ [Formula A] ──┐
        ├→ [Formula B] ──┼→ Aggregation → Output
        └→ [Formula C] ──┘
├─ Concurrent execution
├─ Aggregated results
└─ Use case: Bulk processing
```

**Pattern 3: Conditional Branching**
```
Input → [Condition?] → TRUE → [Branch A]  ┐
                    → FALSE → [Branch B] ──→ Output
├─ Decision-driven routing
├─ Resource-efficient
└─ Use case: Multi-path workflows
```

**Pattern 4: Aggregation**
```
[Input 1] ┐
[Input 2] ├→ [Formula] → [Merge] → Output
[Input N] ┘
├─ Combines multiple inputs
├─ Reduces to single result
└─ Use case: Consensus decisions
```

**Pattern 5: Feedback Loop**
```
Input → [Formula] → Output
   ↑                  ↓
   ←──── [Feedback] ←
├─ Iterative refinement
├─ Continuous improvement
└─ Use case: Optimization
```
