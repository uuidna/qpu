# API overview

Generated by `npm run next` through `configure { kind: 'api' }` on 2026-10-27: what this tree serves, as [platform.claude.com's overview](https://platform.claude.com/docs/en/api/overview) is for the Claude API — one endpoint and every surface around it, read from the handler and the Worker, never written by hand.

**Version 1.4.0** · https://qpu.uuidna.com · https://qpu.psg.bg · https://qpu.ceci.workers.dev

## Architecture

Everything goes through one MCP endpoint: POST /mcp takes JSON-RPC 2.0 (initialize, tools/list, tools/call); every tools/call result is a block addressed by its content, and every other surface serves or carries blocks. No hardware, no network inside the tools, nothing factored beyond N ≤ 21.

## The standard contract

The same surface as an OpenAPI 3.1.0 document, derived from tools/list and the endpoint table and never written by hand: 9 paths, 48 component schemas (every tool and the two JSON-RPC envelopes). It stands inside the discovery document at `/.well-known/qpu.json` and as the MCP resource `openapi://qpu`; the tree's own discovery reads it as `openapi 3.1.0` (9 paths, 83,596 chars), the way it reads every other host's contract.

## Headers

| Request | Response |
|---|---|
| content-type: application/json | etag: the content hash of the result (the clock masked) |
| accept: application/json or text/event-stream | x-qpu-address: the block address (uuidOf(tool + arguments)) |
| if-none-match: "&lt;content hash&gt;" — a 304 answers with no body when the block is the one held | x-qpu-version |
| authorization: Bearer &lt;tenant token&gt; (the docket's writes only) | cache-control: public, max-age=31536000, immutable on addressed replies |
|  | link: &lt;https://uuidna.com/license&gt;; rel="license" |

## Authorization

- **pure**: every tool answers without a credential: the tools are pure functions of their arguments
- **docket**: roles reader, writer, admin per tenant: the RBAC MCP host first (QPU_RBAC_MCP, QPU_RBAC_TOOL), else the tenant's tokens by name; a token at another tenant's host holds no role there
- **never**: no key, token or secret travels through a tool; the client sends them, the tools name them

## Content addressing and the involution

- **address**: uuidOf(tool + JSON(arguments)): the same arguments at any host give the same address
- **hash**: the content hash of the result with the clock masked: the same code gives the same hash at any host
- **involution**: a request naming the hash with If-None-Match is answered 304: the analog is verified digitally at the destination, nothing computed or sent
- **versions**: versions coexist: an earlier version's addresses answer beside the new one's

## The MCP connector

A Claude request mounts this catalogue through the Messages API's MCP connector (both halves, the server and its toolset):

```json
{
  "endpoint": "https://api.anthropic.com/v1/messages",
  "betas": [
    "mcp-client-2025-11-20"
  ],
  "mcp_servers": [
    {
      "type": "url",
      "url": "https://qpu.uuidna.com/mcp",
      "name": "qpu"
    }
  ],
  "tools": [
    {
      "type": "mcp_toolset",
      "mcp_server_name": "qpu"
    }
  ]
}
```

Any other MCP client mounts it as:

```json
{
  "mcpServers": {
    "qpu": {
      "url": "https://qpu.uuidna.com/mcp"
    }
  }
}
```

## Quick tests

list the tools:

```bash
curl -s https://qpu.uuidna.com/mcp -X POST -H 'content-type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

the Clay register read by reflection:

```bash
curl -s https://qpu.uuidna.com/mcp -X POST -H 'content-type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"clay","arguments":{"technique":"reflection"}}}'
```

the involution: ask with the hash and receive 304:

```bash
curl -si https://qpu.uuidna.com/mcp -X POST -H 'content-type: application/json' -H 'if-none-match: "<etag of the reply above>"' -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"clay","arguments":{"technique":"reflection"}}}'
```

the discovery document:

```bash
curl -s https://qpu.uuidna.com/.well-known/qpu.json
```

## Limits

- **shorN**: 21
- **qubits**: 6
- **entry**: the docket's entry bound (413 above it; fold splits what a place cannot hold)
- **quantum**: a client's run stops at QPU_QUANTUM_MS and keeps what it settled

## Errors

| Code | Means |
|---|---|
| -32601 | no such tool or method; the answer names the tools |
| -32602 | invalid params; the answer names the bound the schema sets |
| -32700 | parse error |
| HTTP 304 | the block held is the block asked: nothing sent |
| HTTP 400 | an entry's shape refused, named |
| HTTP 401 | a token with no role at this tenant |
| HTTP 413 | an entry above the bound: fold it |
