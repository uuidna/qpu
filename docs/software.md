# Software

Google Quantum AI's open-source tools, as its software page describes them. Cirq is implemented in this repository; the others are separate projects, listed here as the page states them.

- **Cirq**: an open-source quantum framework for building and experimenting with NISQ algorithms on near-term processors. See [Cirq](/cirq).
- **qsim**: a fast quantum circuit simulator that integrates with Cirq and runs quantum simulations on high-performance classical hardware.
- **Qualtran**: a set of abstractions for representing quantum programs, and a library of quantum algorithms for quantum algorithms research.
- **OpenFermion**: an open-source library for translating chemistry and materials science problems into quantum circuits that run on existing platforms.
- **TensorFlow Quantum**: a quantum machine learning library for rapidly prototyping hybrid quantum-classical machine learning models within TensorFlow.

The page states no version numbers, benchmarks or licence terms for these projects.
